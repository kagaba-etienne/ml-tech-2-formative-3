# Hyperparameter Experiment Results – Kagaba Etienne

**Environment:** Atari Air Raid (`ALE/AirRaid-v5`), DQN with PyTorch and Gymnasium

**Base settings,** kept unless the experiment name says otherwise: learning rate `1e-4`, gamma `0.99`, batch size `32`, epsilon from `1.0` to `0.05` over `50000` steps. Replay buffer `100000`, target update every `1000` steps, `500` episodes. The base loss is MSE, with a gradient step every environment step, observation scaling on the CPU, and no reward clipping.

The name after the experiment number is what changed from that base. `huber` is Huber loss. `fast` is two changes kept together: a gradient step every 4 environment steps, and observation scaling on the GPU instead of the CPU, which reduced the data transferred to the GPU. `clipped` is clipped rewards, `lr3` is learning rate `1e-3`, `gmm8` is gamma `0.8`, and `batch64` / `batch128` are those batch sizes.
